# Editorial and Linking Rules

- Preserve original transcripts. Make corrections visibly and record uncertain speech.
- Never fabricate speech, timestamps, Scriptures, or instructor claims.
- Keep all source recordings outside Git unless publication rights are confirmed.
- Write module materials in order: transcript → outline → notes → summary → nuggets → nutshell.
- In each outline, mark every significant subject transition and its major keys.
- Use relative Markdown links: `[Notes](notes.md)`, `[Master](../../master/outline.md)`.
- For headings, GitHub anchors use lowercase, hyphens for spaces, and omit most punctuation; verify rendered links.
- Link key claims back to transcript headings/timestamps.
- Attribute direct quotes; distinguish paraphrases, interpretations, and biblical text.
- Update master documents by synthesizing overlapping subjects, not pasting entire modules.
- Keep unpublished and unverified content explicitly labeled.
